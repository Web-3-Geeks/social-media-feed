# Social Feed — Frontend

React + Vite + Tailwind client for the Social Media Feed App.

See the [root README](../README.md) for setup, architecture, and deployment.

```bash
npm install
npm run dev      # http://localhost:5173
npm run lint
npm run build
```

Requires `frontend/.env`:

```env
VITE_API_URL=http://localhost:5000/api
```
